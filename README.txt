# Elderly Care Platform — Antigravity Project Bundle

## Files
- `MASTER_PROMPT.md` — consolidated build instructions. Give this to Antigravity first.
- `references/UI_Design_Goal_Original.txt` — your original UI design flow, preserved as supplied.

## Recommended use
1. Extract this ZIP into your project workspace or keep it alongside your project.
2. Open the project folder in Antigravity.
3. Ask Antigravity to read `MASTER_PROMPT.md` and `references/UI_Design_Goal_Original.txt` completely.
4. Ask it to produce the architecture, database design, mobile/web screen map, and Phase 1 plan before coding.
5. Review and approve that plan.
6. Implement Phase 1 only. Keep `DEVELOPMENT_STATUS.md` updated.

## Important
The master prompt integrates the project decisions discussed so far. It does not include API keys, passwords, Supabase credentials, or deployment secrets. Configure those separately using environment variables.
